# auth-api-prisma

> Centralizar cadastro e login com tokens seguros e contrato de API documentado para outras aplicações.

## Problema

Centralizar cadastro e login com tokens seguros e contrato de API documentado para outras aplicações.

## Solução

API REST tipada com Prisma, hash de senha, JWT, validação Yup, Swagger/OpenAPI e PostgreSQL provisionado via Docker Compose — pronta para integração por qualquer frontend.

## Stack

- TypeScript
- Node.js
- Prisma
- JWT
- Docker
- PostgreSQL
